# Coming from macOS

Herald OS runs fullscreen over macOS, or as its own operating system on Linux. Either way, most of
what you reach for has a home here, and Hermes can do most of it for you if you just ask.

## Where things went

| You reach for | In Herald OS |
| --- | --- |
| Spotlight | The command bar: `Cmd+K` (Mac), `Super+Shift+Space` (Linux). Type an app, a file, a command or a question |
| Siri | The voice key (`Alt+Space` / `Super+V`), or "hey Hermes" when the wake word is on |
| Launchpad | All applications: `Cmd+Shift+A` / `Super+A` |
| Finder | The Files page (`Cmd+5` / `Ctrl+5`), or ask "show me the PDFs I downloaded this week" |
| Activity Monitor | The System window (`Super+I` on Linux), or ask "what is using the most memory?" |
| Terminal | The Terminal (`Cmd+8` / `Super+Return`) |
| System Settings | Settings (`Cmd+,` / `Super+,`); on Herald OS Linux, also the menu (`Super+M`) |
| Notification Center | The bell in the menu bar |
| Screenshot (`Cmd+Shift+4`) | `Cmd+Shift+S` / `Super+Shift+S` selects a region and asks Hermes about it |
| Shortcuts and Automator | Automations: on a schedule, or each time something happens |
| Stage Manager and Spaces | Spaces (Personal, Work, Ideas) in the sidebar; on Linux, `Super+1` to `Super+3` |
| The App Store | On Herald OS Linux, the menu's Install, or ask "install Obsidian" |

## What is different

- **Hermes asks before it changes anything.** Reading is free; opening an app just happens; moving,
  renaming or deleting asks you first, every time for anything destructive. Settings > Privacy has
  the rules and the log.
- **You can say what you want instead of finding the button.** "Turn on reduce motion", "switch to
  the Dusk theme", "remind me in 20 minutes to stretch" and "open my last chat about the budget" all
  work from the command bar or by voice.
- **On a Mac, macOS is still there.** `Cmd+Ctrl+F` leaves fullscreen and `Cmd+Q` quits Herald OS;
  your Mac apps, files and settings are untouched.
- **On Herald OS Linux, windows place themselves.** niri, the window manager, lines windows up in
  scrolling columns instead of overlapping them. `Super+F` makes one wide, `Super+T` floats it,
  `Super+O` shows the overview of everything; see [Windows and Spaces](windows-and-spaces.md).

Give it a week: press `Super+K` (Linux) whenever you forget a key, and ask Hermes whenever you
forget where something is.
