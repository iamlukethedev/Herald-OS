# Connections

Connections are the services and tools Hermes can work with beyond your computer. The Connections
page (`Cmd+7` on a Mac, `Ctrl+7` on Linux) brings together everything your Hermes is connected to:

- **MCP servers:** tools from other programs and services that speak the Model Context Protocol,
  such as a database, a note-taking app or a company's API.
- **Messaging platforms:** Telegram, Discord, Slack and the others Hermes's gateway supports, so you
  can talk to Hermes from your phone and automations can post their results there.
- **Toolsets:** groups of Hermes's own tools, some of which need a key or setup.
- **Accounts:** the model providers you are signed in to.

## Connected and Browse

**Connected** lists what is set up, each marked Connected, Needs setup, Error or Disabled. Select
one to see its details: for an MCP server, whether it answers and which tools it offers. From there
you can turn it off or on, reconnect it (which signs you in again in the browser when the service
asks for it), or remove it or sign out.

**Browse** lists what you can add. Choosing something that needs setup opens a conversation where
Hermes helps you set it up: which key to get, and where it goes.

## Good to know

- A messaging platform you turn on or off takes effect when Hermes's gateway restarts.
- Connections belong to your Hermes, so Hermes Desktop and the `hermes` command line see the same
  ones.
- Or just ask: "connect Hermes to my Telegram".
